## Learned
- **`self_checked, high confidence`**: the zero-gradient bug the review found is real and would
  have been silent in practice — `tf.variableGrads` does not error on a `varList` entry with no
  path to the loss, it just omits that variable from the returned `grads` map, so a first run of
  the (not-yet-implemented) training sketch would have appeared to work (no throw, critic loss
  would visibly decrease) while the actor never moved. Worth carrying forward as a general lesson
  for this project's future tensor-graph work: a `varList`-scoped `tf.variableGrads` call is
  exactly as safe as its weakest gradient path, and nothing in tfjs's API surfaces a broken one.
- **`self_checked, high confidence`**: fresh-checkout `npm install` gaps are a real, recurring
  failure mode for this loop, not just a one-off — `node_modules` is untracked and this
  environment's containers appear to start from a clean clone each run. Distinct from the
  Apple-Silicon/darwin install issues `loop/GOAL.md` deprioritizes (`ADR-0002` decision 6): this
  was a plain missing `npm install` on the pinned Linux/tfjs-node combination that already works
  here, not a platform-support question, so it doesn't fall under that carve-out and was worth
  fixing rather than skipping.
