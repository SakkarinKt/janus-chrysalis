# Stand-up archive — index

The loop's daily stand-ups from 2026-07-04 to 2026-09-28: 83 files, 8,043 lines. Archived on 2026-11-09 as part of the loop revamp. Nothing was deleted or edited; the files were moved with `git mv`, so `git log --follow` still shows each one's history.

## Finding an old reference

Documents written before the archive cite stand-ups as `reports/standup/YYYY-MM-DD.md`. Every such path now lives at `reports/standup/archive/2026-Q3/YYYY-MM-DD.md`. Historical documents (the stand-ups themselves, `reports/quality/`, manifests) were not rewritten.

## What to know before reading them

- **Run numbers are unreliable.** Headings say "run N" literally, restart at "run 1", and repeat. Use the date.
- **17 of the 83 mention an exhausted priority list.** From 2026-09-09 the loop had no authorized work left; those stand-ups re-verify the same state. The open question they carry (what the loop should do when its list is empty) is in `2026-09-24.md` under "Decisions needed". It was never answered on the PR; it is the reason `loop/GOAL.md` is being rewritten around an experiment queue.
- **Six were never merged.** 2026-09-23 to 2026-09-28 sat in open loop PRs with no review. They are copied here unedited from each PR's head so the PRs can be closed without losing them.
- **Gaps are real.** No stand-ups exist for 2026-08-14 to 2026-08-19, and the loop was paused after 2026-09-28.
- **`run N` in `loop/GOAL.md` v3** counts `reports/standup/*.md` on `main`. That count is now 0, so the rule must be redefined before the loop is re-enabled.
