## Learned

- self_checked, high confidence: the count-only ratchet had exactly the residual gap the #33
  review named — a config-level tsc failure can produce a small nonzero in-repo count that reads
  as "fewer errors, still under baseline" rather than "zero files typechecked". The
  `tsconfig.json`-substring check is sufficient on its own to catch every config-diagnostic
  variant tried here (`TS18003` no-inputs, bad `--target`, malformed JSON) because tsc always
  reports config/CLI-level problems either against the config file path itself or with no
  per-file location prefix at all — I kept the second regex as a narrower, independent signal
  in case a future tsc version reports a config error without mentioning the filename.
