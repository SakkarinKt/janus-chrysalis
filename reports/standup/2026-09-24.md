## Learned

- **[NOTE, self_checked, high confidence] PR #81's new disposal comment gives the wrong reason,
  though its code is right.** In `0013`, line 178 on #81's head, the comment says the
  `tf.variableGrads` closure "isn't wrapped in tf.tidy (it can't be — tf.variableGrads owns the
  tape)". In tfjs 4.22.0 it is wrapped. `engine.gradients` runs the closure as
  `this.tidy('forward', f)` (`node_modules/@tensorflow/tfjs-core/dist/engine.js:868`). The
  intermediates the closure creates are freed automatically, and only the returned `value` and the
  `grads` survive. Disposing those two is still correct and needed, so only the comment's reasoning
  needs fixing. Repro (scratch script, run from the repo root with `node`, output below):

  ```js
  import * as tf from "@tensorflow/tfjs-node";
  const w = tf.variable(tf.tensor2d([[0.5, -0.2], [0.1, 0.3]]));
  const x = tf.tensor2d([[1, 2]]);
  const base = tf.memory().numTensors;
  const { value, grads } = tf.variableGrads(() => {
    let h = x; const kept = [];
    for (let t = 0; t < 15; t++) {
      h = tf.tanh(tf.matMul(h, w)); kept.push(h);
      tf.sum(h).dataSync()[0]; // dropped tensor, like rewardHead.predict(...).dataSync()[0]
    }
    return tf.mean(tf.concat(kept, 0));
  }, [w]);
  // net after call → 2; after tf.dispose(value); tf.dispose(grads) → 0
  ```

  Output: `{"tfjs":"4.22.0","horizon":15,"netTensorsAfterVariableGrads":2,"netTensorsAfterDisposingValueAndGrads":0,"gradKeys":1}`.
  About 47 intermediate tensors were created (3 ops × 15 steps, plus `concat` and `mean`), and 2 survived. A consequence for the sketch: tensors
  that are created inside the closure and then dropped, such as line 164's
  `rewardHead.predict(...).dataSync()[0]` or the `valueTensor`/`continueTensor` copies, do **not**
  leak. The closure's own tidy frees them.
