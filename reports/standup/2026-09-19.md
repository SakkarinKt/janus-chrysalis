- `docs/explainers/0013`'s training-sketch bug the review caught (computing `criticLoss`/`actorLoss`
  *before* calling `tf.variableGrads` rather than inside its closure) is a real gradient-tracing
  bug, not a style nit: tfjs's tape only records ops that execute during the call to
  `tf.variableGrads`'s function argument, so a loss tensor built beforehand and merely referenced
  inside the closure would carry no traceable path back to the trainable weights, regardless of
  the tensor's own value being correct. Worth remembering as a class of bug for any future
  `tf.variableGrads` usage in this codebase, not specific to this one sketch.
