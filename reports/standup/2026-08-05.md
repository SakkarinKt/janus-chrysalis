## Learned

- **`tf.customGrad`'s `value` must not be the identical tensor object as the input being
  differentiated, or the custom gradient silently doesn't apply.** `self_checked, high confidence` —
  reproduced directly. First `stopGradient` draft returned `value: x` (the literal input); its test
  (gradient should be exactly zero) failed with the *ordinary* gradient of whatever consumed the
  output leaking through instead (a `sum(mul(stopGradient(x), weights))` loss returned `weights`
  itself as the gradient, as if `customGrad` weren't applied at all) — not an error, not `NaN`, a
  silently wrong answer that would have shipped if the test had trusted the value without checking
  it was actually zero. Fixed by returning `x.clone()` instead — a distinct tensor with identical
  values, which does trigger the custom gradient node correctly. This project's other `customGrad`
  use (`straightThroughEstimator` in `src/model/rssm.ts`) doesn't hit this, because its `value: hard`
  is never the tensor being differentiated (`logits` is) — so it's specific to the "differentiate
  the same tensor whose forward value you're passing through unchanged" case, i.e., exactly what a
  `stopGradient` implementation does. Worth watching for in any future `tf.customGrad` use in this
  codebase that returns one of its own inputs as `value`.
- **DreamerV3's KL-balance formula/defaults** (`L_dyn = max(1, KL[sg(q)||p])`, `L_rep = max(1,
  KL[q||sg(p)])`, `beta_dyn = 1`, `beta_rep = 0.1`, arXiv:2301.04104): `medium confidence,
  self_checked`. Primary-source fetch 403'd again this run (`arxiv.org/abs/2301.04104`,
  `ar5iv.labs.arxiv.org`, `arxiv.org/pdf/2301.04104` — all three tried), consistent with
  `notes/lit-map.md`'s standing tooling caveat that this is a persistent constraint for autonomous
  runs, not a one-off. Cross-checked via `WebSearch`, which returned a snippet quoting the paper's
  equations and coefficient values directly (not just a paraphrase), and a second independent search
  summary corroborated the same "clipped below 1 nat" framing. Capped at medium per the lit-map
  convention rather than treated as verified — flagging for a primary-source pass in a future
  interactive session, the same gap `notes/adr-0002-js-ml-stack.md`'s `tf.stopGradient` claim sat in
  before being corrected by directly running the pinned dependency instead of only searching about
  it.
